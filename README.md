##Book Nest

A responsive book discovery web application that allows users to search,
explore, and save books using the Open Library API.
## Deployed site
https://liliosee1.github.io/Phase-onee-capstone-project/

## Features

. Search books by title, author, or keyword
. Browse books from Open Library API
. Add / remove favorites
.Data storage using localStorage
.Fully responsive design (mobile + desktop)
. Loading, error, and empty states
. Multi-page navigation (Home, Favorites, About)

##Tech Stack

HTML5 
•Tailwind CSS 
•JavaScript (ES6 Modules) 
• Open Library API
• localStorage 
• Git & GitHub

## structure
 #index.html:Home page (search + books)
 #favorites.html : Saved books page
 #about.html : Project info page

 #index.js : Main app logic
 fav.js : Favorites page logic
 
 #js
  fetchBooks.js : API requests
    storage.js :localStorage handling

 ## How Book nest work
.Books are fetched from the Open Library API
.Users can search for books in real-time
.Clicking “Add to favorites” stores data in localStorage
.Favorites are displayed and can be removed anytime
