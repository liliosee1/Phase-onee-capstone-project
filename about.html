About Book Explorer

Book Explorer is a responsive, interactive, API-powered web application built as a frontend capstone project using HTML, Tailwind CSS, and JavaScript. It demonstrates real-world concepts like API integration, state management, and responsive UI design.

What it does

  • Browse and search millions of books from Open Library API
  • Save and remove favorite books (localStorage)
  • Fully responsive mobile-first design
  • Loading, error, and empty states
  • Multi-page navigation system

Tech Stack

HTML5 Tailwind CSS JavaScript ES6 ES6 Modules async/await localStorage Open Library API GitHub

Learning Outcomes

  • Build responsive websites using Tailwind CSS
  • Handle DOM events and UI updates with JavaScript
  • Fetch and display data from APIs
  • Structure code using ES6 modules
  • Use GitHub for collaboration workflow
